# onnx/.github

Default community health files for the [ONNX](https://github.com/onnx) GitHub
organization. GitHub uses a file from this repository for every public
repository in the organization that does not have its own copy.

| File | Purpose |
|---|---|
| [`FUNDING.yml`](FUNDING.yml) | Sponsor button linking to the [ONNX Community Travel Fund](https://crowdfunding.linuxfoundation.org/initiatives/onnx-community-travel-fund) |

A repository shows the Sponsor button only when Sponsorships is enabled in its
settings (Settings → General → Features).

Add files here with care: any supported community health file placed in this
repository (for example `CONTRIBUTING.md`, `SECURITY.md`, or issue templates)
becomes the default for all repositories in the organization that lack their
own. See GitHub's documentation on
[default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
